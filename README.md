# Linguagem C - Estudos e Desenvolvimento

Repositório dedicado ao estudo e prática da linguagem de programação **C**. O conteúdo abrange diversos tópicos fundamentais da programação estruturada, com foco em exercícios e projetos desenvolvidos para aprimoramento e consolidação do aprendizado.

---

## Conteúdo do Repositório

O conteúdo está organizado em pastas que representam módulos ou tópicos específicos da linguagem C.

* **C_apr2/**: Pasta principal que contém todos os arquivos de exercícios (`.c`) organizados por tópico.
    * **Estrutura Condicional:** Exemplos e exercícios com `if/else`.
    * **Estrutura de Repetição:** Exemplos e exercícios com `while`, `for`, e `do/while`.
    * **Tipos de dados:** Exercícios introdutórios sobre variáveis e tipos básicos.
    * **String:** Exercícios sobre manipulação de cadeias de caracteres.
    * **Vetores / Matrizes:** Exemplos e exercícios com arrays e estruturas de dados.
    * **Ponteiros:** Implementações e exercícios sobre o uso de ponteiros.
    * **Funções / Alocação_Memória:** Conteúdo relacionado a funções e alocação dinâmica.
* **LICENSE**: Licença do projeto (**GPL-3.0** - baseada na sua imagem).
* **README.md**: Documentação do repositório.

---

## Objetivos

* **Dominar** os conceitos de programação estruturada em C.
* **Compreender** e aplicar estruturas de controle de fluxo (condicionais e repetição).
* **Entender** o uso e a importância de ponteiros e alocação de memória.
* **Resolver** problemas práticos de algoritmos, utilizando as estruturas de dados básicas (vetores e strings).

## Instalação e Execução

Para compilar e executar os exercícios, você precisará de um compilador C (como o GCC) instalado em seu sistema.

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/CarolinaBis/C.git
    ```

2.  **Navegue até a pasta de um exercício (Exemplo: Estrutura Condicional):**
    ```bash
    cd "C_apr2/Estrutura Condicional"
    ```

3.  **Compile o arquivo C usando o GCC:**
    ```bash
    # Compila o arquivo Ex1.c e cria um executável chamado 'ex1'
    gcc Ex1.c -o ex1
    ```

4.  **Execute o programa compilado:**
    ```bash
    ./ex1
    ```
